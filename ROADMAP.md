# Nasir Bespoke Roadmap

The roadmap is intentionally staged. Each phase should preserve the private, server-side AI boundary and the men's-only product focus.

## Phase 1 — Private AI try-on foundation

Status: implemented

- Staff authentication.
- Person and fabric capture.
- Optional outfit reference.
- Men's visual garment catalog.
- Suit-first bespoke configuration.
- Server-side deterministic prompt compiler.
- GPT Image 2 generation.
- Result comparison and download.
- Usage/history metadata.
- Optional private image storage.
- Responsive Midnight Atelier UI.

## Phase 2 — Bespoke garment intelligence

Status: partially implemented / next major product phase

- Deeply configure Sherwani, Nehru Jacket, Kurta Pajama, Indo-Western, Shirt, Waistcoat, and Coat/Blazer.
- Replace temporary reference photography with official Nasir Bespoke assets.
- Add structured showroom/customer permissions.
- Implemented: owner/admin history authorization, retention expiry and retryable deletion.
- Next: storage-inventory reconciliation for unrecorded orphans.
- Add MFA, account lifecycle, and audit reporting.
- Add stronger image decode and privacy controls.

## Phase 3 — 2D preview engine

Status: proposed

- Controlled front, back, three-quarter, and detail preview states.
- Non-generative garment composition where reliable.
- Preview-to-generation handoff.
- Configuration-aware visual comparison.

## Phase 4 — 3D digital tailoring engine

Status: proposed / long term

- Measurement-aware body representation.
- Digital pattern and garment construction.
- Interactive 3D views.
- Tailoring and order-system integration only after the visualization foundation is proven.

## Deliberately deferred

- CRM
- inventory
- payments
- subscriptions
- order management
- customer accounts
- social sharing
- AI chat
- arbitrary prompt editing
- automated correction loops
- automatic four-view generation
